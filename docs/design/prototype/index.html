How to read the table

  • Bumper ring is context used against the model limit.
  • Score reels are coins: every token billed so far.
  • Insert light is status: running, idle, stuck, error, ended.
  • Drop targets fall one per finished turn.
  • Extra balls are subagents. The main ball spins faster as coins burn faster.
  • TILT WARNING at 80% context. BALL SAVED means it compacted.
